### Contributors

- @rmcar17 added support for free-threaded Python.



### ENH

- Wheels are now built for free-threaded Python. Calls into IQ-TREE
  remain serialised, as IQ-TREE is not thread-safe, but other threads can run
  while IQ-TREE does. While a piqtree function runs, the process's working
  directory is changed and stdout/stderr are silenced, which may affect other threads.
